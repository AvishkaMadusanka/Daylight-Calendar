DAYLIGHT — SRI LANKA SPECIAL DAYS & CHROME EXTENSION
======================================================

Daylight Calendar එක දැන් Google Chrome Extension එකක් (Manifest V3) ලෙස සම්පූර්ණයෙන්ම සකසා ඇත!
විශේෂ දිනයකට දින 3කට පෙර සිට Google හෝ ඕනෑම Website එකක Browsing කරන විට ඉහළ දකුණු කෙළවරේ (Top-Right) අලංකාර Floating Timeline Widget එකක් දිස්වේ. කැමති විටෙක එය Close (✕) කිරීමේ හෝ Minimize (─) කිරීමේ පහසුකමද ඇත.

------------------------------------------------------
1. GOOGLE CHROME EXTENSION එකක් ලෙස INSTALL කරගන්නා ආකාරය (3 පියවරෙන්):
------------------------------------------------------
1. Google Chrome Browser එක Open කරන්න.
2. Address bar එකේ පහත ලින්ක් එක type කර Enter ඔබන්න:
   chrome://extensions
3. ඉහළ දකුණු කෙළවරේ ඇති "Developer mode" (toggle එක) On කරන්න.
4. ඉහළ වම් කෙළවරේ ඇති "Load unpacked" බොත්තම Click කරන්න.
5. මෙම `Daylight_Calendar` folder එක තෝරා "Select Folder" ඔබන්න.

දැන් Daylight Calendar එක Google Chrome Extension එකක් ලෙස සාර්ථකව Install වී ඇත! Chrome toolbar එකේ Daylight Icon (✳) එක දිස්වනු ඇත.

------------------------------------------------------
2. TOP-RIGHT FLOATING TIMELINE WIDGET එක ක්‍රියා කරන ආකාරය:
------------------------------------------------------
- විශේෂ දිනයක් (Holiday, Poya, Birthday, Milestone) පැමිණීමට දින 3කට පෙර සිට ඔබ Google හෝ ඕනෑම වෙබ් අඩවියක සැරිසරන විට:
  * තිරයේ ඉහළ දකුණු කෙළවරේ (Top Right) අලංකාර 3-Day Countdown Timeline Widget එකක් දිස්වේ.
  * එහි [ Day 3 ] ──► [ Day 2 ] ──► [ Eve ] ──► [ Event ] ලෙස දින 3ක Timeline එකක් පෙන්වයි.
  * [ ✕ Close ] බොත්තම ඔබා අවශ්‍ය ඕනෑම මොහොතක එය Close කර දැමිය හැක.
  * [ ─ Minimize ] ඔබා එය කුඩා Pill Badge එකක් බවට පත් කළ හැක.
  * [ Open Calendar ] click කර සම්පූර්ණ Calendar එක නව Tab එකකින් බලාගත හැක.

------------------------------------------------------
3. ප්‍රධාන FEATURES:
------------------------------------------------------
1. Chrome Extension (Manifest V3) + Standalone Web App
2. Background Service Worker (background.js) — දින 3කට පෙර Chrome Badge එක සහ Native Notifications ලබාදේ.
3. Content Script (content.js & content.css) — Google සහ වෙබ් අඩවි වල Top-Right Timeline එක පෙන්වයි.
4. Live Digital Countdown Clock (Days, Hours, Minutes, Seconds)
5. Days-Left Calculator (දින ගණක යන්ත්‍රය)
6. 3-Day Notification Alert Modal + Audio Chime
7. Sri Lanka 2026 Public Holidays & Poya Days + Annual Fixed Holidays
8. Personal Special Days (Local Storage & Chrome Storage Sync)
